Knox

Problem: AI coding agents suffer from catastrophic amnesia, losing architectural rationale, decisions, and constraints across sessions and tool switches.

A persistent, cross-platform knowledge graph and Model Context Protocol (MCP) server built in Rust. It captures architectural decisions, pre-flight guardrail constraints, and developer human edits across disparate coding sessions (Antigravity, Cursor, Claude Code, Gemini CLI), giving AI agents long-term causal memory.

Measurable Detail: 8 focused MCP tools (knox_begin, knox_context, knox_check, knox_trace, knox_record, knox_handoff, knox_ask, knox_update); tool definition footprint budgeted ≤ 850 tokens; 50-pair calibrated guardrail with 0.60 overlap threshold; 5.46 MB LZMA setup wizard.
