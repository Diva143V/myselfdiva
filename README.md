# Diva Portfolio

Personal portfolio site for **Diwakar Venkat Peddada** — Software Engineer, AI Developer, and research-focused builder.

**Live site:** [myselfdiva.netlify.app](https://myselfdiva.netlify.app)

## Stack

- HTML5, CSS3, vanilla JavaScript
- Canvas-based chroma-key video rendering

## Local development

Serve the folder with any static file server:

```bash
npx serve .
```

Or open `index.html` directly (some features work best over HTTP).

## Project structure

```
├── index.html      # Main page (inline CSS + JS)
├── favicon.svg     # Site icon
└── assets/
    ├── chroma-keyed-video.webm
    └── download.wav
```
